# GitHub Copilot活用 - 実践セキュリティ修正ハンズオン

このハンズオンでは、実際に動作するセキュリティ脆弱性のあるアプリケーションを使って、GitHub Copilotを活用したセキュリティ修正を実践的に学習します。

## ラボの概要

> [!IMPORTANT]
> このラボの技術や生成AIツールは確率論的であるため、スクリーンショットや
> コードスニペットと実際の体験に違いが生じる可能性があります。

このハンズオンでは、SQL Injection攻撃の実演からGitHub Copilotを使った修正まで、セキュリティ脆弱性の実体験と修正を順を追って学習します。

0. [環境のセットアップ](./0-prereqs.md)
1. [脆弱性アプリケーションのセットアップ](./1-vulnerable-app-setup.md)
2. [SQL Injection攻撃の実演](./2-vulnerability-demo.md)
3. [GitHub Copilotによるセキュリティ修正](./3-copilot-fix.md)
4. [修正版の動作確認と総括](./4-verification.md)

## シナリオ

あなたは開発チームのメンバーとして、既存のWebアプリケーションにセキュリティ脆弱性が報告されました。このハンズオンでは以下を実践します：

- **脆弱性の実体験**: 実際のSQL Injection攻撃を成功させ、セキュリティ脆弱性の危険性と影響を理解
- **効率的な修正**: GitHub Copilot Chatを活用して、脆弱なコードをプリペアードステートメントを使った安全なコードへと効率的に修正
- **修正効果の確認**: 修正後のコードが攻撃を防げることを確認し、セキュリティ修正の効果を実感
